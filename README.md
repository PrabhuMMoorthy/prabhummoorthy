# Prabhu's Web Applications Collection

A collection of interactive web applications and tools built with vanilla HTML, CSS, and JavaScript. This repository showcases various utility applications and learning projects, all designed to be lightweight and accessible directly in your browser.

## 📋 Projects Overview

### Core Applications

#### **📝 Venmurasu Quote Reader** (`venmurasu-quote-reader.html`)
An interactive quote reader and explorer with a beautiful UI. Features include:
- Browse and read quotes from classic literature
- Search functionality with dynamic filtering
- Canvas-based visualization for quote data
- Persistent state management

#### **📚 Venmurasu Notes** (`venmurasu-notes.html`)
A comprehensive note-taking application featuring:
- Rich note creation and editing
- Search and filter capabilities
- Data persistence using browser storage
- Clean, intuitive interface

#### **💰 Expense Tracker** (`expense.html`)
A full-featured expense management application:
- Track income and expenses
- Categorize transactions
- Generate reports and insights
- Visual summaries of spending patterns

#### **🏦 Loan Calculator** (`loan.html`)
Calculate and analyze loan scenarios:
- EMI calculations
- Amortization schedules
- Comparative analysis tools
- Interest computation

#### **📊 Comparator Tool** (`comparator.html`)
Side-by-side comparison utility for data analysis:
- Compare multiple items or datasets
- Highlight differences and similarities
- Export comparison results

#### **💬 Chat Application** (`chat.html`)
Interactive messaging interface featuring:
- Real-time message display
- User-friendly conversation management
- Message history tracking

#### **📹 My YouTube** (`my-youtube.html`, `my-youtube.js`, `my-youtube.css`)
YouTube video management and organization tool:
- Browse and organize video collections
- Search functionality
- Responsive video player interface

#### **📝 Notepad** (`notepad.html`)
Simple text editor for quick notes:
- Clean, distraction-free interface
- Auto-save functionality
- Light and fast

#### **✨ Quotes Display** (`quotes.html`)
Random quotes and inspirational content viewer with:
- Beautiful quote presentation
- Random quote generator
- Share capabilities

#### **🏠 Main Portal** (`index.html`)
Central hub featuring:
- Navigation to all applications
- Application overview
- Quick access links

## 🛠️ Technology Stack

- **HTML** (47%) - Structure and markup
- **JavaScript** (34%) - Application logic and interactivity
- **CSS** (9%) - Styling and responsive design

## 🎯 Key Features Across Applications

- **No Dependencies**: All applications use vanilla JavaScript (no frameworks required)
- **Lightweight**: Minimal file sizes for fast loading
- **Browser-Based**: Works directly in any modern web browser
- **Responsive Design**: Optimized for desktop and mobile devices
- **Data Persistence**: Utilizes browser storage for maintaining user data
- **User-Friendly**: Intuitive interfaces for easy navigation

## 🚀 Getting Started

### View Applications
1. Clone or download this repository
2. Open any `.html` file in your web browser
3. Start using the application immediately

### Access via GitHub Pages
All applications are hosted on GitHub Pages for easy online access. Simply open the repository in your browser to get started.
